## Notes
- A251 and A255 already have a one-shuffle `--placebo` flag; for the calibration the shuffle must be repeated (seeded draws) with companions held at 200 sets. The states of the 200 sets of A251 (6 compartments) and A255 can be cached and only the person index permuted per draw. Their placebo permutes `m.to_numpy()` rows (A251) or tissue frames (A255) before gene selection, equivalent to permuting states.
- A251 companion sets are drawn from the mean log intensity of the women (`lm`, l.224); gene sets dropped if a gene is missing (`women_states` returns None), so the number of sets may be below 200 in the real run (200 in score_tests.csv).
- A227: `perm_null_raw` (l.98) permutes uniformly across patients within cohort, NOT within chemistry stratum; states themselves are centred within stratum. The pooled pseudo statistic uses weights over cohorts per set index: set j in cohort A and set j in cohort B are different gene sets (seeds per cohort), pooled by index (`pooled_pseudo`).
- A227 Holm is over scored primaries; the companion enters the verdict only as `statistic > pseudo_q95`. A271 added `--kind responsive` to the same script (outputs `A227_tme_compartment_pairing/output/responsive/`): myeloid 0.581 vs responsive q95 0.637 (not passing), T/NK 0.539 vs 0.569 (not passing).
- A138: `score_h138_responsive.py` has `strat_null` (permutation within TSS or plate, `stratified_null.csv`) -- a stratified pairing null, not a companion placebo.
- A138 H138.4: the registered pass rule is permutation p<0.05; the q95 0.261 is a descriptive companion (`companion_q95`, `score/tests.csv`); H138.4-R (q95 0.3097) is the responsive version.
- A263: L has no pairing null; placebo of the donor labels makes all couplings ~0, so L (ratio of medians) will be unstable or NaN (the real run already drops sets with brain coupling 0: 26 matched sets). The placebo needs a definition of the "rule" under null (q05 of L of companions vs clock L per draw), and a per-draw refit of 401 sets (baboon 49 min, human 4.4 h, sheep 13.8 h per full pass): only baboon is feasible for many draws; human and sheep only with few draws or a reduced set number.
- Controlled access: A263 human uses GTEx per-donor expression with `Hardy` scale selecting the fast cohort (`_shared.cohort`, `gtex.load(hardy=...)`); the Hardy scale and times are protected phenotypes. Placebo outputs must be aggregates (null distributions of L, shares, percentiles), never per-donor tables or per-donor states. TCGA, GEO (skin, MuTHER prep, surgical cohorts), sheep, baboon and the A227 single-cell cohorts are public-derived: no per-donor restriction flagged in the code (not verified against PROVENANCE.md).
- Not found: any placebo run of A138, A227, A263 in output/ folders or in the results_preliminary.md headings for these amendments.
