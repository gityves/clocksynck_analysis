# Builders: natural experiments and single-cell cancer cohorts

Each folder has `build.py` with `build(level=..., donors=...) -> (pb, donors)` from the processed files under
`$SCCC_DATA`, `from_legacy(level=...)` (the table the legacy code built, converted) and a docstring (source, accession,
legacy builder replaced, choices). `python build.py` runs the checks below. Shared helpers: `natexp_common/`
(standard table, majority-assay rule, `compare`), `cancer_common/` (copy-number calling, marker compartments, cohort
loaders). Pseudobulks are summed with `clocksync.pseudobulk` (chunked h5ad, or in-memory AnnData of the 14 clock genes
with each cell's genome-wide count as `depth` for csv / h5 / loom / mtx sources). Every pseudobulk with at least one
cell is kept: thresholds (cells, donors per compartment) are applied by the analyses that are pre-registered with them.
Several tables per dataset are levels of the same cells: `build(level)` / `from_legacy(level)`, first level = default.

Check status: **slice** = `build()` on a few donors (files of those donors) equals `from_legacy()` rows of those donors
(counts, depth, n_cells; maximum absolute difference 0). **full** = whole table compared. **synthetic** = reader tested on
a small synthetic file (the real input is not on disk).
